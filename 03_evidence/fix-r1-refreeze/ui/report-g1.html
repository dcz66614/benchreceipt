What this tool can and cannot prove

BenchReceipt can prove: whether the Git commit / tree, run environment, command summary, CI run and attempt, job and matrix, and report bytes collected in the current workspace satisfy the declared binding rules — and where the first inconsistency is, when they do not.

BenchReceipt cannot prove: that the test logic is correct, that test assertions are strong enough, that the code has no bugs, or that a workflow author did not maliciously forge environment variables or reports. SHA-256 detects accidental mix-ups and byte changes; it is not a cryptographic signature and does not authenticate a malicious runner. This report does not replace SLSA, in-toto, Sigstore, or GitHub Artifact Attestations.
